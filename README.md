# 🚀 Blog Pessoal

Um blog pessoal construído com o gerador de sites estáticos [Hugo](https://gohugo.io/). Anotações de estudo e projetos pessoais.

---

## 🛠️ Tecnologias Utilizadas

- **Gerador de Site Estático:** [Hugo](https://gohugo.io/) (Versão Extended)
- **Tema:** [Congo](https://jpanther.github.io/congo/)
- **Hospedagem:** [Cloudflare]
---

## 📁 Estrutura de Pastas Principais

```text
.
├── archetypes/       # Templates para criação de novos posts
├── content/          # Onde ficam os arquivos Markdown (.md) das publicações
│   └── posts/        # Todos os artigos e publicações
├── layouts/          # Modificações e personalizações de layout
├── static/           # Arquivos estáticos (imagens, favicon, PDFs)
├── themes/           # Tema instalado no projeto
└── hugo.toml         # Arquivo principal de configuração (ou config.toml)
